WorldPay 2.0 · App 接口文档

RESTful 风格 · 统一前缀 /card/api · 共 292 个接口，其中 App 端约 221 个。

BASE URL

https://<host>/worldpay
本地：http://localhost:8023/worldpay

鉴权

Header token: Bearer <jwt>
登录接口返回 token

语言

Header language: en | zh | zh_TW
缺省 en

编码

Content-Type: application/json
字符集 UTF-8

① 响应：统一返回明文 JSON（不再做 AES 加密）： {"rtncode":200,"msg":"success","data":...}。rtncode=200 表示成功，500 表示业务失败，403 表示未登录 / 无权限。

② 请求体：推荐直接提交明文 JSON；兼容旧客户端，也可 AES 加密后提交，格式为 {"data":"<AES(Base64)>"}，算法 AES/ECB/PKCS5Padding，key 为 16 字节字符串（向服务端索取）。

③ 不支持加密的接口（只能传明文 JSON）：/card/api/sign/encryption、/card/api/sign/decryption、/card/api/webhook/reset-addres、/card/api/webhook/agent-notify、/card/api/wallet/topin-usdt-notify、/card/api/file/upload-image、/card/api/file/api-upload-image。

④ GET 请求无请求体；参数直接放在 query / path 中。

⑤ 免鉴权接口：注册、登录、谷歌验证码、邮箱验证码、忘记密码、配置信息、App 版本、签名、Webhook、链上充值回调。

请求示例

POST /worldpay/card/api/app-user/login
Content-Type: application/json
language: en

{ "userEmail": "a@b.com", "userPassword": "***" }

响应示例（明文）

{ "rtncode": 200, "msg": "success", "data": { "token": "Bearer eyJ..." } }
